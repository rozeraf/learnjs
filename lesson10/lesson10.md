### План Урока 10: Утилитные типы (Utility Types)

**Цель:** Научиться использовать встроенные утилитные типы TypeScript (`Partial`, `Readonly`, `Pick`, `Omit`, `Record`) для создания новых типов на основе существующих, делая код более гибким и DRY (Don't Repeat Yourself).

**Концепции, которые мы затронем:**

1.  **`Partial<T>`:**
    *   Делает **все** свойства типа `T` необязательными (`?`).
    *   Идеально для функций обновления, где мы можем передать только часть полей.
    *   **Пример:** `Partial<User>` сделает `name` и `age` опциональными.

2.  **`Readonly<T>`:**
    *   Делает **все** свойства типа `T` неизменяемыми (`readonly`).
    *   Полезно для создания безопасных, немутируемых объектов.

3.  **`Pick<T, K>`:**
    *   "Выбирает" из типа `T` только те свойства, ключи которых (`K`) мы перечислили.
    *   **Пример:** `Pick<User, 'name'>` создаст тип, у которого есть только свойство `name`.

4.  **`Omit<T, K>`:**
    *   "Выбрасывает" из типа `T` свойства, ключи которых (`K`) мы перечислили, оставляя все остальные.
    *   **Пример:** `Omit<User, 'age'>` создаст тип, у которого есть все свойства `User`, кроме `age`.

5.  **`Record<K, T>`:**
    *   Создаёт тип объекта (словарь/хэш-мапу), где ключи имеют тип `K`, а значения — тип `T`.
    *   Ты уже использовал его в 8-м уроке! `Record<Shape, number>`.

---

**Практика:**

Для всех заданий мы будем использовать этот базовый интерфейс:
```typescript
interface User {
  id: number;
  name: string;
  email: string;
  age: number;
  isAdmin: boolean;
}
```

1.  **Задача "Обновление пользователя" (`Partial`):**
    *   Создай объект `userToUpdate` с типом `Partial<User>`, который содержит только `name` и `age`.
    *   Напиши функцию `updateUser(id: number, data: Partial<User>)`, которая выводит в консоль `id` и переданные данные.
    *   Вызови эту функцию.

2.  **Задача "Замороженный объект" (`Readonly`):**
    *   Создай объект `const secureUser: Readonly<User> = { ... }` с полным набором полей.
    *   Попробуй изменить одно из его полей, например, `secureUser.name = "Новое имя";`. TypeScript должен выдать ошибку.

3.  **Задача "Аватар пользователя" (`Pick`):**
    *   Создай новый тип `type UserAvatar = Pick<User, 'id' | 'name'>;`.
    *   Создай объект типа `UserAvatar`.

4.  **Задача "Публичный профиль" (`Omit`):**
    *   Создай новый тип `type PublicUserProfile = Omit<User, 'email' | 'isAdmin'>;`.
    *   Создай объект типа `PublicUserProfile`.

5.  **Задача "Словарь пользователей" (`Record`):**
    *   Создай тип для словаря, где ключами будут `id` пользователей (в виде `string`), а значениями — их имена: `type UserDirectory = Record<string, string>;`.
    *   Создай объект `directory` этого типа с несколькими записями, например: `{'1': 'Алиса', '2': 'Борис'}`.
